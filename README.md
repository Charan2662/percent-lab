# Percent Lab

Percentage practice for SSC CGL, SBI PO and IBPS PO.

## Run
Extract this ZIP and open index.html in a modern browser. For a local server, run `python -m http.server 8000` from the extracted percent-lab folder and visit http://localhost:8000.

## Files
- index.html: page structure
- style.css: responsive styling
- bank.js: 12 question generators and formula cards
- app.js: practice modes, timer, scoring, mistake notebook and browser-local progress

No build step, packages, API keys or backend are required. Fonts load from Google Fonts when online; fallback fonts work offline. Progress is saved in localStorage for the current browser and origin.

## Hosting
Upload all four source files together to any static web host, or place them at the root of a GitHub Pages repository. This archive does not include deployment credentials or the private hosting configuration.

Questions are original generated exam-style practice, not official previous-year questions. Number combinations and patterns may repeat. Sprint mode contains 10 questions with an 8-minute timer.
